# Data

Dataset: `StressLevelDataset.csv`

Source: Student Stress Factors dataset on Kaggle  
https://www.kaggle.com/datasets/samyakb/student-stress-factors

The analysis uses `stress_level` as the outcome and `study_load`,
`sleep_quality`, and `social_support` as the main explanatory variables.

The original dataset is kept unchanged. Data-quality checks and all analysis
decisions are documented in `notebooks/analysis.ipynb`.
